# Charm the Commuter: Forecast a City That Isn't — one line

The entry is Sunny with a chance of sentient fog in Oozle-on-Sea; it mostly wants to talk about its cat, so leave ten minutes early for your commute. The program writes exactly that one line to /output/entry.txt.
